# 手工测试用例表

> 逐条人工执行的测试用例，适用于答辩演示、发布前冒烟或回归确认。

| # | 模块 | 用例名称 | 前置条件 | 步骤 | 预期结果 | 实际 | 结论 |
|---|------|---------|---------|------|---------|------|------|
| M-01 | 登录 | 正确口令登录 | 服务运行中 | 输入 admin/正确密码 → 点击登录 | 200，跳转到预约页，显示管理员身份 | ✅ | 通过 |
| M-02 | 登录 | 错误口令 | 服务运行中 | 输入 admin/错误密码 | 401，提示"用户名或密码不正确" | ✅ | 通过 |
| M-03 | 登录 | 连续错误 5 次锁定 | 服务运行中 | 连续 5 次错误口令 | 第 6 次返回 429 LOGIN_LOCKED | ✅ | 通过 |
| M-04 | 注册 | 正常注册 | 服务运行中 | 切换注册 Tab → 输入新用户名+密码+确认 → 提交 | 自动登录，角色 USER | ✅ | 通过 |
| M-05 | 注册 | 重名注册 | 已有 stu2026 | 用相同用户名注册 | 409 USERNAME_TAKEN | ✅ | 通过 |
| M-06 | 预约 | 正常预约 | 存在空闲场次 | 选实验室+日期 → 点击可预约场次 | 200，场次显示"我的预约" | ✅ | 通过 |
| M-07 | 预约 | 重复预约 | 已预约某场次 | 再次预约同场次 | 409 ALREADY_RESERVED | ✅ | 通过 |
| M-08 | 候补 | 满员候补 | 场次已满 | 点击"加入候补" | 200，状态 WAITING | ✅ | 通过 |
| M-09 | 候补 | 空位引导直约 | 场次有余位 | 尝试候补 | 409 SLOT_AVAILABLE，提示直约 | ✅ | 通过 |
| M-10 | 取消 | 取消预约 | 已有预约 | 点击"取消预约" | 200，状态 CANCELLED，如有候补已补位 | ✅ | 通过 |
| M-11 | 签到 | 窗口内签到 | 场次已开始且在窗口内 | 点击"立即签到" | 200，状态变为"已签到" | ✅ | 通过 |
| M-12 | 签到 | 窗口外签到 | 场次已开始且窗口已过 | 尝试签到 | 409 STATE_CONFLICT | ✅ | 通过 |
| M-13 | 通知 | 查看通知 | 有未读通知 | 点击通知按钮 → 查看列表 → 标记已读 | 未读计数减少，列表更新 | ✅ | 通过 |
| M-14 | 统计 | 导出 CSV | admin 已登录 | 管理工作台 → 选日期 → 导出 CSV | 下载 .csv，Excel 打开有 BOM 和合计行 | ✅ | 通过 |
| M-15 | 管理 | 发布场次 | admin 已登录 | 发布表单填日期范围+容量 → 提交 | "发布完成，新建 N 个场次" | ✅ | 通过 |
| M-16 | 安全 | CSRF 防护 | 无有效 CSRF 令牌 | 用 curl 发 POST 不带 X-CSRF-Token | 403 CSRF | ✅ | 通过 |
| M-17 | 安全 | 限流 | --rate-burst 3 | 连续发 4 次写操作 | 第 4 次返回 429 RATE_LIMITED | ✅ | 通过 |
| M-18 | 界面 | 窄屏布局 | 浏览器宽度 390px | 打开预约页 | 卡片单列排列，无溢出 | ✅ | 通过 |

## 使用说明
- 每轮发布前至少执行 M-01~M-06 作为冒烟测试。
- M-17 需以 `--rate-burst 3` 启动服务。
- M-11/M-12 需以 `--checkin-window 60` 启动并等待场次开始。
- 全部用例可在自动化集成实验中找到对应自动化版本（T 编号见 tests/README.md）。
