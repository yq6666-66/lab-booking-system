# 毕业论文大纲与图表清单（v1，待确认）

> 课题名称：**基于 C 语言的实验室预约与候补系统的设计与实现**
> 依据：教师版研究计划（docs/plans/）、docs/CONTRACT.md、docs/TEST_REPORT.md 及仓库内全部实测证据。
> 正文目标篇幅约 1.5 万字（可按学校格式要求调整）；确认本大纲后再展开正文。

## 章节结构与字数分配

### 摘要（中英文，各约 350 字）
问题（并发争抢、重复请求、进程中断、签到爽约）→ 方法（C11 + CivetWeb + SQLite 事务/唯一约束 + 请求回执去重 + 扫描线程）→ 结果（720 次并发请求零重复占用、20 次中断恢复全部正确、单元 16 + 集成 25 项全通过）→ 关键词：实验室预约；候补队列；事务一致性；幂等请求；C 语言

### 第 1 章 绪论（约 1500 字）
- 1.1 选题背景与意义：高校开放实验室预约的现实问题（占而不用、冲突、候补无序）
- 1.2 国内外现状：LibreBooking 等系统调研；现有系统对轻量部署、并发正确性、可恢复性的不足
- 1.3 主要工作：四项（系统设计与实现；一致性与去重机制；故障恢复验证；签到爽约闭环）
- 1.4 论文组织结构

### 第 2 章 相关技术（约 1500 字）
- 2.1 C11 与 MinGW-w64 构建链
- 2.2 CivetWeb 嵌入式 HTTP 服务（多线程模型、回环部署）
- 2.3 SQLite：WAL、BEGIN IMMEDIATE、局部唯一索引、外键与完整性检查
- 2.4 cJSON 与 libsodium（密码哈希、随机令牌）
- 2.5 前端：原生 HTML/CSS/JS（无框架的理由：与嵌入式后端对称、可审计）

### 第 3 章 需求分析（约 1800 字）
- 3.1 角色与用例：普通用户 / 管理员；用例图
- 3.2 功能需求：场次查询、预约、取消、候补/退出、自动补位、签到与爽约、站内通知、改密与会话管理、记录分页、管理与统计、CSV 导出
- 3.3 业务规则（BR1–BR8）：一场次一预约、FIFO 候补、取消补位同事务、去重回执、过期冻结、停用实验室语义、签到窗口与爽约补位、权限边界
- 3.4 非功能需求：并发正确性、可用性（进程中断恢复）、安全性（口令哈希/CSRF/Origin）、可维护性（契约文档与幂等迁移）

### 第 4 章 系统设计（约 3000 字）
- 4.1 总体架构：分层（浏览器 → CivetWeb 接入 → 会话/CSRF → 业务层 → 数据访问 → SQLite），模块图
- 4.2 数据库设计：ER 图；9 张表结构（v2）；schema v1→v2 只追加列的幂等迁移设计
- 4.3 状态转换设计：预约（CONFIRMED/CANCELLED+USER/NO_SHOW）与候补（WAITING/WITHDRAWN/PROMOTED/SKIPPED）状态机
- 4.4 关键机制设计：
  - 并发一致性：BEGIN IMMEDIATE 短事务 + 每场次一条 CONFIRMED 的局部唯一索引
  - 请求去重：request_receipts 回执表（同键同参重放 / 同键异参冲突 / 500-503 不落回执）
  - 取消补位：取消与 FIFO 补位同一事务；禁用账号跳过
  - 签到与爽约：签到窗口、补位预约以补位时刻为签到起点、扫描线程单事务回收
  - 故障恢复：WAL + synchronous=FULL；两类中断点（提交前 86 / 提交后 87）的行为推导
- 4.5 接口设计：REST 风格、统一响应封套、错误码表（概览，全文见附录）

### 第 5 章 系统实现（约 3500 字）
- 5.1 开发环境与构建脚本（正式版/测试版 TEST_FAULTS/加固版三目标）
- 5.2 HTTP 接入与会话安全实现（Cookie、CSRF、Origin、Host 校验、16KB 上限）
- 5.3 事务与去重核心代码解析（booking() 主流程、回执保存/重放分支）
- 5.4 取消补位与爽约扫描实现（promote()、sweep_once()）
- 5.5 通知、改密与会话管理实现（其他会话立即失效的语义）
- 5.6 分页与统计导出实现（BOM CSV、合计行）
- 5.7 前端实现与降级重试（sessionStorage 保留未确认请求编号）

### 第 6 章 系统测试（约 3000 字）
- 6.1 测试策略与环境（独立客户端、独立实验库、固定请求数）
- 6.2 单元测试（16 用例表：纯函数/数据库不变量/业务层直调）
- 6.3 功能与安全回归（T01–T09、T13–T19 摘表）
- 6.4 并发实验（T10）：1/5/10/20 并发 ×20 轮共 720 请求，结果表 + 零重复占用结论 + 响应时间分布
- 6.5 故障注入恢复实验（T11）：86/87 两类 ×10 轮，重启状态/重放/补位核对
- 6.6 签到爽约闭环实验（T22）：超时回收、FIFO 补位、双向通知
- 6.7 静态分析与加固构建：-fanalyzer 零告警；工具链无 ASan 的限制与 FORTIFY+SSP 替代（如实陈述）
- 6.8 调试过程记录（论文亮点）：两处 SQL 绑定格式串错位致段错误、爽约-补位死循环、前端分页 id 拼接、迁移回填遗漏——现象/定位/修复
- 6.9 浏览器端到端验收（引用 ui-r3 截图）

### 第 7 章 总结与展望（约 700 字）
- 完成工作对照教师版计划逐项核对；局限（单机、回环、无审批流）；展望（门禁联动、跨校区、多实验室容量）
